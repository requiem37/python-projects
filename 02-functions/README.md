Привет, это задачка из моей практики по функциям, сейчас расскажу про что эта программа:
Это счетчик самой найбольшей цены.
Что делает функция:

`most_value(shop)` принимает словарь, где ключ это название товара, а значение цена.

Из товаров дешевле 100 она выбирает самый дорогой и возвращает его название. Если ни один товар не дешевле 100, возвращает `None`.
